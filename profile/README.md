# StackToIT

**The migration tool for STACKIT.**

StackToIT is a rule-based, deterministic command-line tool that turns an existing cloud or VMware estate into a reviewable migration package for STACKIT: every resource with a migration class, a STACKIT target and the reason; STACKIT Terraform drafts for supported units; target architecture diagrams; an ordered execution plan; and a decision register for the questions the code cannot answer.

- Sources: AWS, Microsoft Azure, Google Cloud, Huawei Cloud, Alibaba Cloud and Oracle Cloud estates written in Terraform or OpenTofu, and VMware estates exported with RVTools.
- Runs locally on macOS and Linux, needs no cloud credentials and changes nothing in any cloud.
- No generative AI: the same input and rule version give the same result.
